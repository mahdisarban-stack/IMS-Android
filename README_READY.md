# IMS Android - آماده ساخت APK

این نسخه موبایل مستقل است و دیتابیس خودش را داخل حافظه برنامه نگه می‌دارد.

## ساخت APK روی Windows
1. وارد پوشه android_app شوید.
2. فایل build_apk.bat را اجرا کنید.
3. بعد از پایان، فایل APK داخل پوشه build تولید می‌شود.

این نسخه از دوربین برای بارکد استفاده می‌کند و به PC یا اینترنت نیاز ندارد.
