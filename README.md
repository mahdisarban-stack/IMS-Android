# IMS Mobile - مرحله ۳

این پوشه نسخه اولیه Android نرم‌افزار IMS است.

## امکانات فعلی
- اتصال به API نسخه PC از طریق Wi-Fi/LAN
- تست اتصال به PC
- جستجوی کالا با بارکد
- ثبت ورود و خروج
- پشتیبانی از واحد تکی/کارتن
- صف آفلاین برای عملیات زمانی که PC یا شبکه در دسترس نیست
- همگام‌سازی عملیات معوق با `/api/v1/sync/push`

## اجرای آزمایشی روی PC
```bash
pip install -r requirements.txt
python main.py
```

## ساخت APK
برای ساخت APK با Flet، روی سیستمی که Flet و ابزارهای Android نصب شده‌اند:
```bash
flet build apk
```

پس از ساخت APK، آن را روی گوشی نصب کنید.

## اتصال گوشی به PC
1. روی PC سرور `api_server.py` را اجرا کنید.
2. گوشی و PC را به یک Wi-Fi وصل کنید.
3. در برنامه گوشی آدرس مشابه زیر را وارد کنید:
   `http://192.168.1.100:5000`
4. اگر Windows Firewall سؤال کرد، دسترسی شبکه خصوصی را مجاز کنید.

> دوربین بارکد در مرحله بعد اضافه می‌شود؛ در این مرحله ورود دستی بارکد برای تست اتصال و منطق همگام‌سازی استفاده شده است.
